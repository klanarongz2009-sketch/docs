## Understanding simulation status

Every game on Zap Games displays a real-time operational status. Here's what each status means:

<AccordionGroup>
  <Accordion title="DORMANT">
    The game simulation is currently offline. It is not accepting new players. This status is temporary — games are cycled back online regularly. No action is needed on your part; simply check back later.
  </Accordion>

  <Accordion title="LIVE">
    The game is running and accepting players. Select the game from your dashboard and click **AUTHENTICATE** to enter.
  </Accordion>

  <Accordion title="INITIALIZING">
    The simulation is starting up. Wait a few moments and the status will update to **ACTIVE**.
  </Accordion>
</AccordionGroup>
